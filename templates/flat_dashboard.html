3. Regular Expression - URL Validation

Pattern currently implemented in WebGuard:

^https?://[A-Za-z0-9.\-\[\]:]+(?::\d{1,5})?(?:/.*)?$
Enter a URL and test the pattern.
Important: Regex checks URL syntax. WebGuard's separate target validation enforces the localhost-only restriction. A regex match does not mean the target is authorized or safe to scan.

4. Regular Expression - Header Validation

Header-name pattern from the FLAT engine:

^[!#$%&'*+.^_`|~0-9A-Za-z-]+$
Enter a header name to test.

5. DFA - HTTP / HTTPS Scheme Recognition

WebGuard's DFA recognizes the HTTP or HTTPS scheme prefix.

States:
q0 - Start q1 - H q2 - HT q3 - HTT q4 - HTTP q5 - HTTPS qF - Accepted
Waiting for input.
Acceptance condition: The URL must begin with http:// or https://. Complete URL syntax and localhost restrictions are checked separately.

7. FLAT Integration in WebGuard

Step 1: Scanner receives the target URL.
Step 2: Regex checks URL syntax.
Step 3: DFA recognizes HTTP or HTTPS scheme.
Step 4: Localhost-only target validation checks the target.
Step 5: FSM controls scanning and analysis stages.
Step 6: WebGuard generates and stores the scan report.
