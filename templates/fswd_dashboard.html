2. Frontend Technologies

HTML

HTML provides the structure of the WebGuard dashboard. It defines headings, statistics cards, scan tables, vulnerability sections and navigation links.

Project file: templates/index.html

CSS

CSS controls the dashboard appearance, including dark theme, cards, tables, colours and responsive layout.

Project file: static/style.css

JavaScript

JavaScript fetches scan statistics and scan history from Flask APIs and dynamically displays the results.

Implemented functions:

  • loadDashboard()
  • displayFindings()
  • fetch("/api/stats")
  • fetch("/api/scans")

3. Backend Technologies

Python

Python implements the security scanner, security checks, risk calculation, report generation and database operations.

Flask Framework

Flask connects the browser dashboard with the Python backend through application routes.

GET /

Loads the main WebGuard dashboard.

GET /cn

Loads the CN dashboard.

GET /flat

Loads the FLAT dashboard.

GET /api/scans

Returns saved scan history as JSON.

GET /api/stats

Returns scan statistics as JSON.

GET /scan/<scan_id>

Displays the selected scan's details.

4. Database Integration

MongoDB Atlas

WebGuard stores scan results in MongoDB Atlas. The database contains the scan target, risk score, risk level, findings and scan status.

Database: webguard

Collection: scan_history

Project file: database.py

PyMongo

PyMongo connects the Python application to MongoDB Atlas. It is used to insert scan results and retrieve scan history.

  • connect_database()
  • save_scan_result()
  • get_scan_history()
  • close_database()

5. API Communication

Scan Statistics API

GET /api/stats

Returns:

  • Total scans
  • High-risk scans
  • Total vulnerability findings
  • Latest scan information

Scan History API

GET /api/scans

Retrieves scan records from MongoDB Atlas and sends them to the frontend as JSON.

6. Report Generation

JSON Report

Stores structured scan information and vulnerability findings.

HTML Report

Presents scan results and security findings in a browser-readable report.

CSV Report

Exports vulnerability information into tabular format for spreadsheet applications.

7. WebGuard Data Flow

  1. The Python scanner performs an authorized local scan.
  2. The scanner analyses the HTTP response.
  3. The risk engine calculates the risk score.
  4. Reports are generated in JSON, HTML and CSV formats.
  5. Scan results are saved to MongoDB Atlas.
  6. Flask retrieves saved scan records.
  7. JavaScript fetches data from Flask APIs.
  8. The browser displays statistics and vulnerabilities.
